# Interactive Excel VBA Dashboard — Company Operations Dataset

## What it does

A fully interactive Excel dashboard built on a 1,200-row dataset covering Sales, Expenses, and Employee records. VBA-driven dynamic slicers and pivot-table-linked charts let a user filter and drill down in real time, without manually rebuilding pivot tables for every new view.

## How it was built

- Raw data cleaned and structured in a dedicated sheet
- A separate `BUILD DASHBOARD` sheet holds the pivot tables, charts, and VBA-driven slicer controls
- VBA macros handle the dynamic filtering logic so the dashboard updates without manual pivot refresh steps

## How to use it

1. Download `Interactive_Excel_VBA_Dashboard.xlsm`
2. Open in Excel and enable macros (required for the slicer/filter logic to run)
3. Go to the `BUILD DASHBOARD` sheet and interact with the slicers to filter by department, entity type, location, or status
