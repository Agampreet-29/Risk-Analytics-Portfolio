# Adidas US Sales Dashboard

## What it does

A Power BI sales analysis dashboard built on Adidas's US retail sales data, covering retailer performance, regional trends, and profitability by product line and sales method.

## Dataset

Retailer-level transaction data including retailer name and ID, invoice date, region/state/city, product category, price per unit, units sold, total sales, operating profit, operating margin, and sales method (In-store vs. Online).

## Files in this folder

- `Adidas_us_saale_dashboard.pbix` — the original Power BI file (open in Power BI Desktop)
- `Adidas_US_Sales_Datasets-6.xlsx` — the underlying sales dataset
- `adidas_sales_dashboard.html` — a standalone interactive HTML version of the dashboard, viewable in any browser without Power BI

## How to view it

- **Fastest:** open `adidas_sales_dashboard.html` directly in a browser — no software required
- **Full version:** open `Adidas_us_saale_dashboard.pbix` in Power BI Desktop to see the live data model and DAX measures
