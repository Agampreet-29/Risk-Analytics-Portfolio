# HR Attrition Analysis Dashboard

## What it does

Analyzes employee workforce data to identify attrition patterns and turnover drivers, presented through an interactive dashboard for HR decision-making.

## Dataset

Employee-level records including department, designation, join/exit dates, tenure, exit reason, manager, performance rating, attrition risk flag, notice period, and rehire eligibility.

## Analysis approach

- Segmented employees by status (Active / Exited) to isolate attrition trends
- Broke down exits by department, tenure band, and stated exit reason (relocation, performance, compensation, personal, career change) to surface which factors correlate with turnover
- Used the pre-tagged "Attrition Risk" field (Low/Medium/High) to flag active employees worth watching

## How to use it

1. Download `Dashboard_Automation.xlsm`
2. Open in Excel and enable macros
3. Explore the dashboard views to filter by department, exit reason, or attrition risk level
